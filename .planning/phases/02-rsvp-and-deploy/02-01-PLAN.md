TASK 2-1: Apps Script receiver with tested validation
Model: haiku
Goal: `Code.gs` the user pastes into Apps Script; validation is unit-tested locally.
Read first: app.js (field names: name, attending, guests, website)
Change:
  - `apps-script/Code.gs` (plain Apps Script, no `import/export`):
    - `function validateRsvp(p) -> {ok: boolean, spam?: true, error?: string, row?: [name, attendingLabel, guests]}`
      rules: `website` non-empty → `{ok:true, spam:true}`; name trimmed 1–100 chars else error "name"; attending must be `yes`|`no` else error "attending"; guests integer 1–10 when yes, forced 0 when no, else error "guests"; if name starts with `= + - @` prefix it with `'` (spreadsheet formula injection guard); attendingLabel `Có` / `Không`.
    - `function doPost(e)`: `validateRsvp(e.parameter)`; if ok and not spam → `SpreadsheetApp.getActiveSpreadsheet().getSheets()[0].appendRow([new Date(), ...row])`; always return `ContentService.createTextOutput(JSON.stringify({ok, error})).setMimeType(ContentService.MimeType.JSON)`; wrap in try/catch → `{ok:false, error:'server'}`.
    - `function setup()`: if sheet row 1 empty, write headers `Thời gian | Tên | Tham dự | Số người`.
  - `apps-script/validate.test.mjs` (node:test): read Code.gs with `fs`, run with `vm.runInNewContext(src, ctx)`, then assert:
    yes+guests 2 → row `['An','Có',2]`; no+guests 5 → row `['An','Không',0]`; name '  ' → error 'name'; attending 'maybe' → error 'attending'; guests '11' and '0' with yes → error 'guests'; name '=1+1' → row[0] === "'=1+1"; website 'x' → spam true.
Do NOT touch: index.html
Ponytail rung: Apps Script built-ins; node:test + vm (stdlib)
Constraints: 1. Never trust client values — all checks server-side here. 2. No secrets in repo (the web-app URL is public by design).
Verify: `node --test apps-script/validate.test.mjs` → all pass
Done when: tests pass; commit.
Depends on: none (Phase 1 done)
