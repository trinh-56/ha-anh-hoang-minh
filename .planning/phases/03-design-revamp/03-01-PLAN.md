## Shared spec (every task)

**Design unit.** On `:root`: `--u: calc(min(100vw, 480px) / 1080)`. One design pixel = `calc(N * var(--u))`. Every position and size below is in design px, measured from the PNG; tune by eye. Do not use `container-type`.

**Fonts. All lettering is live HTML text; no lettering images.**
- Script: `--script: 'Aston Script', cursive`, from `assets/fonts/AstonScript.ttf` (a copy of `assets-v2/Aston Script.ttf`, single weight 400). Use it only for: "Hà Anh", "Hoàng Minh", "&", "the", "Countdown", "Timeline", "Thank You". It lacks most Vietnamese letters (ạ ầ ể ơ ư đ …), so never set any other Vietnamese text in it.
- Everything else: Georgia Pro, using the existing `@font-face` rules and system Georgia fallback for Vietnamese. "SAVE", "DATE" and "AND" are Georgia Pro.
- Script sizes below are starting values: match glyph height to the design.

**Motion.** Keep the existing opacity scroll-fade (`.fade`, `FADE_TARGETS`). Remove the progress bar, `strip-sway`, `settle-left`, `settle-right`.

**Accessibility floor (overrides pixel match).** Inputs and selects use `font-size: max(16px, 44 * u)` so iOS does not zoom. Every control is at least 44px tall. Visible focus states stay. Decorative images get `alt=""`.

SVG sizes: `door-seal` is 726×727, `envelop-with-seal` is 1280×995.
